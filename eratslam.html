Research / Event-Based Perception, State Estimation & Mapping

eRatSLAM: Biologically Inspired Event-Based Localization and Mapping

Combining event-based visual odometry, sensor fusion, and place recognition with biologically inspired mapping to estimate motion, recognize revisited places, and build cognitive maps.

DemonstrationsFrameworkPublications

The research problem

How can asynchronous visual events support motion estimation and mapping? This research adapts RatSLAM, a framework inspired by rodent spatial-navigation mechanisms, to event-camera inputs and develops components for odometry, velocity refinement, and recognition of previously visited places.

The project brings together three related conference publications, each addressing a different component of biologically inspired event-based localization and mapping.

Demonstrations

Framework

Motion estimation

A statistical event-alignment method based on a spatio-temporal Poisson point-process model estimates ego-motion from sparse, asynchronous event streams. A Kalman filter fuses event-derived velocity estimates with IMU measurements to refine translational velocity estimation.

Place recognition

Time surfaces encode the spatial and temporal history of events. Compact visual templates are stored and compared with the current view using sum-of-absolute-differences matching. Recognizing a stored template identifies a revisited place and supports loop-closure detection.

Cognitive mapping

A continuous attractor neural network represents planar position and heading in a three-dimensional pose-cell space. Motion estimates shift its activity packet through path integration, while recognized places inject activity to anchor the pose estimate. The experience map links these pose and place representations into a topological network of locations and paths.

Research contributions

  • Adapted biologically inspired RatSLAM to use event-based visual odometry for cognitive-map construction.
  • Developed event-aligned velocity estimation and incorporated Kalman filtering with inertial measurements to refine motion estimates.
  • Developed an event-based place-recognition module using time surfaces and template matching for loop-closure detection.
  • Evaluated the related methods on recorded real-world event-camera datasets.
